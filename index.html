Format help

       Natural mode. Write numbers with the variable right after them: max, 3U, 8H. Constraints are name, terms, operator, right-hand side, for example Limit, 50U, 80H, <=, 80000. Anything written after the right-hand side becomes an extra constraint with the same operator and 0 on the right, so Limit, 50U, 80H, <=, 80000, -10U+0.5H adds −10U + 0.5H ≤ 0. Terms can also be joined in one piece, like 50U+80H<=80000. Variables are found from the letters after numbers (or names already in the model). Use int, U, bin, H or free for types.

       CSV mode. First line max, 3, 5; constraint lines name, 1, 0, <=, 4; optional vars, A, B, types, int, cont, free.

       Separate statements with new lines or semicolons. Lines starting with # are ignored.
